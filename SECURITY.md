# Security and privacy

This is a public **translation-only** repository. Tendo's application code, user data, backups, signing material, and private Git history do not belong here.

Please **never** submit credentials, tokens, private screenshots, backups, private task content, home addresses, or details from another person's schedule. Use invented examples when discussing language problems.

For sensitive vulnerabilities, please use **GitHub → Security → Report a vulnerability** if the repository owner has enabled private vulnerability reporting. If this option is unavailable, contact the Tendo developer through the official Tendo support channel; **do not open a public Issue with exploit details or secrets**. No private contact email is embedded here because none has been verified.

I review security reports privately and coordinate any necessary change with Tendo's separate private engineering and release process. GitHub Actions in this repository need only read public contents; they have no private-repository, deployment, or app-signing credentials.
