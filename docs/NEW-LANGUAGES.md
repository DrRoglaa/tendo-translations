# Requesting a new language

I'd love to hear which language you'd like Tendo to speak next. Head to **Issues → New issue → Request a New Language** and share the language name, code if known (for example `pt-BR`), and whether you'd like to help.

A locale is more than a flag. Portuguese in Brazil, Portuguese in Portugal, and other regional variants can need different wording, date conventions, plurals, and voice behavior. If you're unsure which locale code fits, that's fine; describe the language naturally.

## What happens next?

I'll check community interest, contributor availability, spelling/grammar and plural needs, accessibility layouts, Apple language support, and whether it fits an approved Tendo release. I won't promise a specific date or label a language supported until the real app has been validated. New public packs require a fresh review of private source strings and an updated export baseline — ordinary PRs cannot create arbitrary new catalog keys or locales.

All requests are welcome. One good reviewer is more valuable than 500 very confident robots.
